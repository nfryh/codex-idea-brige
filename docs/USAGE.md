# 使用说明

本文中的 IDEA 指 IntelliJ IDEA，JetBrains 提供的集成开发环境。Hooks 是 Codex 的生命周期回调，Model Context Protocol 是供模型调用受限编辑器工具的模型上下文协议。

## 环境与首次配置

插件不锁定 IDEA 的精确补丁版本，不检查 Codex 是否等于某个版本。已有验证覆盖 IDEA 2026.2.1（构建号 `262.9437.185`）与 Codex 0.161.0；这些是验证记录，不是精确版本要求。

当前终端接口最低要求 IntelliJ 平台 `262`（2026.2 系列），插件运行需要 Java 25。更早的大版本尚未验证，取消精确版本限制不代表所有历史版本都可用。兼容声明不设置上限，后续平台可能改变实验性终端接口；已执行的验证范围见 [项目介绍](../README.md#验证范围)。本版仍以 macOS 本地终端为范围。

1. 从 GitHub Releases（版本发布页面）下载或通过源码构建得到 `codex-terminal-companion-1.0.0-dev.6.zip`，在“设置 → 插件 → 从磁盘安装插件”中选择该文件。
2. 打开“设置 → 工具 → Codex IDEA Companion”。设置页自动查找已安装的 Codex 并填入配置目录。若你在终端设置了 `CODEX_HOME`（指定 Codex 配置目录的环境变量），确认此处使用相同目录。
3. 点击“预览安装或更新配置”，审核具体回调命令及可选工具配置，批准后写入。安装器自动沿用现有 TOML（配置文件格式）回调表或用户级 `hooks.json`，不再让用户手动选择来源。批准安装同时保存设置。
4. 首次增加回调后，在原生 Codex 的 `/hooks` 审核并信任回调；重新打开终端，仍然只输入 `codex`。

IDEA 终端内由插件自动适配启动方式：本机 Codex 声明支持进程内运行时，命令入口自动使用这一原生方式，让回调和模型上下文协议工具能够继承该终端的连接信息。只在 IDEA 私有缓存中准备一个小型启动脚本，不替换本机 Codex，不改用户 Shell 配置、登录、项目信任或命令审批。IntelliJ IDEA 外部的 Codex 启动方式不变。IDEA 内该会话不使用共享后台服务，关闭终端会结束该终端里的前台会话；用户无需理解或手写相应参数。

**不需要在插件中再次授权项目。** 打开的本地项目直接建立联动；原生 Codex 负责项目信任和命令审批。文件访问仍限于当前项目内容根，敏感文件和符号链接边界检查保留。自动附加上下文、附近代码和工具读取未保存文档仍是可选设置。

安装器将 `bridge-client.jar`（独立 Java 桥接程序）放到 `<Codex home>/idea-companion/v1/`。目录中的 `v1` 表示桥接协议版本，不是 Codex 版本限制。通过“Codex 联动诊断”查看实际回调和终端连接；配置存在不代表已成功收到回调。

## 日常引用

打开源码文件，IDEA 终端栏会显示当前文件；选中代码后显示实际选区覆盖的行数。按默认快捷键或右键“发送选区引用到 Codex”，终端草稿中出现例如 `@gradlew#L5-6`，已有输入保留，没有自动提交。实时状态显示在 IDEA 终端栏，不声称修改了 Codex 自己的输入提示。

|动作|macOS 默认键位映射|其他默认键位映射|
|---|---|---|
|添加选区|Command + Option + K|Control + Alt + K|
|添加当前文件|Command + Option + Shift + K|Control + Alt + Shift + K|
|查看引用队列|Command + Option + Q|Control + Alt + Shift + Q|

内容在动作发生时冻结，包括未保存文本和真实行范围。成功接收引用后直接聚焦对应的已有终端，你继续输入问题并自行提交。插件不发送回车，不修改剪贴板或文件。删除草稿里的完整引用标记后，对应快照不会在提交时继续发送。

单个已验证的 Codex 终端自动确定目标；多个终端须明确选择。启动后即能发送引用，不要求先提交一条问题。引用先属于已经验证的终端，原生首次回调执行时关联真实会话；未绑定列表不会被顺便消费。没有正在运行的 Codex 终端时明确提示，既不插入普通 Shell，也不留下本次隐形待发快照。重复恢复同一会话时，可以明确选择允许交接的终端，其他冲突记录不消费队列。新版和经典终端分别使用本机提供的终端接口；已登记为执行中的任务不能发送新的草稿引用。

“发送当前文件引用”直接插入文件路径，不再弹出仅路径或全文选择框；项目树多选也是路径引用。文件搜索排除敏感路径和二进制；索引期间只搜索已打开文件并说明状态。显式编辑器引用敏感文件时会要求单次确认，不扩大自动上下文或工具权限。

新安装默认开启自动带入当前文件和选区。升级保留已有设置；若之前关闭了自动附加，需要在“设置 → 工具 → Codex IDEA Companion”勾选对应选项。关闭自动附加时，终端栏仍显示选择反馈并注明关闭状态。

“查看 Codex 引用”提供精确正文、目标、字节数、未保存标记、捕获时间、过期与路径状态、移除、刷新、重新排队和重新指定目标。“已交接给命令行”只代表桥接程序写出结果并确认，不代表模型已逐项理解。

每队列最多 16 项，每个正文快照最多 131072 字节，每队列正文最多 2097152 字节；一次实际附加内容最多 24576 字节，完整回调输出最多 65536 字节。快捷发送在插入草稿前检查正文总量，超限时撤回本次新增内容并要求缩小选区。待发引用 30 分钟后需要刷新或明确重新加入。

通过“设置 → 键位映射”搜索 `ICB.AddSelection`、`ICB.AddCurrentFile`、`ICB.FindFileAndAdd`、`ICB.ShowContextQueue`、`ICB.SelectSession` 配置快捷键。选区、当前文件和引用队列动作已经提供默认快捷键。自定义键位映射可能已有绑定，可在此处修改。

## 工具和差异

工具为 `ide_get_context`、`ide_read_document`、`ide_get_diagnostics`、`ide_open_file`、`ide_show_diff`；完整参数见 [本地协议说明](PROTOCOL.md)。工具不能运行命令、写文件或读取根外路径。未保存内容读取需要独立许可，显式附件确认不会扩大工具许可。

诊断只复制已有高亮，明确报告 `READY`（完成）、`PENDING`（尚未完成）或 `UNAVAILABLE`（无法取得），不启动全项目分析。

每轮只为已引用或当前相关文件记录有限磁盘基线，任务结束后展示原生只读比较。比较分别标注提交前磁盘基线、独立编辑器快照和文件删除状态；编辑器快照不表示内容已经保存或修改已经应用。“查看本轮已记录文件差异”选择列表展示 `reviewId`（比较记录标识），可将该标识明确提供给工具。磁盘变化可能包含用户或外部程序的并行修改，不自动归因给模型。

磁盘读取由插件自动管理的普通 Java 进程执行，使用安全目录描述符逐层访问当前项目内容根。这解决 IDEA 文件系统包装缺少安全目录接口的问题。进程受并发和时间限制，最后一个使用项目关闭或插件卸载时回收并删除私有桥接归档。用户按原流程运行 Codex 即可。

## 移除和限制

先在设置页点击“预览移除本插件配置”，批准后仅移除完整匹配清单的条目；用户修改过的配置保留并说明。全局联动关闭并撤销凭证，不终止正在运行的 Codex，不恢复整份旧备份，不删除会话历史。随后通过 IDEA 卸载插件。

如果直接在 IDEA 删除插件而未运行配置移除操作，用户级回调配置仍在；没有连接变量的外部终端会无输出退出，旧终端会收到联动不可用警告。清理配置需要使用保留的安装清单审核，不猜测删除用户条目。

正文和凭证不进入持久化设置。退出 IDEA 后未发送引用清空。手动修改的专属 TOML 段在升级时要求审核；卸载时原样保留。文件搜索使用项目文件索引匹配名称或路径片段，单次最多展示 1000 个候选。
